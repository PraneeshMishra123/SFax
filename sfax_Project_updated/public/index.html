About SFAX

Some things are too personal for a group chat or a screenshot. SFAX lets you write to someone close to you and have it printed and sealed at the post office nearest them, for their eyes only.

The post office only ever sees your name. The message itself never appears on a screen there. It goes straight to the printer and into an envelope with the recipient's name on it.

Security and privacy

What we can see, and what we cannot

What SFAX can see

  • The sender's name
  • Who it is for (the name you typed)
  • The destination post office PIN
  • When it was sent
  • Its status: waiting, sealed or printed

What SFAX cannot read

  • The message itself
  • Both addresses
  • Both email IDs
  • Anything in the printout

These are encrypted in the sender's browser before they are sent.

Honest limits

  • If the post office has not installed the app yet, a waiting message is protected by a temporary key held on the SFAX server. Until the app picks it up, whoever controls that server could open it. After that, only the app can.
  • SFAX keeps an encrypted backup of each post office key, opened only with an offline master key, so lost keys can be recovered.
  • Printed paper is paper. Whoever holds it can read it.
How the encryption works
  • The message: encrypted in your browser with a fresh AES-256-GCM key. That key is locked with the post office's RSA-OAEP key (3072-bit, SHA-256).
  • Waiting messages: if the post office has no key yet, the message key is locked with a temporary key held by the server (ECDH P-256, HKDF-SHA-256, AES-256-GCM). When the app creates its key, the server re-locks the message to it and forgets the temporary copy.
  • Passwords: never stored. Only a salted scrypt hash is kept. Login sessions end when a password is reset.
  • Connection: everything travels over HTTPS.
How keys are made and protected
  • The post office key pair is created by the SFAX Print app on the post office computer, using the computer's cryptographic random generator.
  • The private key is stored encrypted by Windows (DPAPI) and is held in memory only while the app is signed in. The website never has it.
  • An encrypted backup of each private key is kept so a lost key can be recovered. It can only be opened with a master key that the SFAX owner keeps offline.
  • A key file moved to a second computer is locked with a passphrase (scrypt and AES-256-GCM).
How the website and the Print app talk to each other

The app signs in over HTTPS, downloads only the locked message, unlocks it in memory and sends it to the printer. The server only hands messages to up-to-date versions of the app, and every print is recorded in an activity log that never contains message text. Logins are rate limited, and every request is checked against the signed-in account.

Independent security audit

SFAX has not yet had an independent security audit. It uses standard, widely reviewed algorithms through the browser's built-in Web Crypto API, and its access rules are covered by automated tests.

For post offices

Everything you need to start printing

  • A Windows 10 or 11 PC with an internet connection
  • A dot matrix printer, such as an Epson LX, FX or LQ, or a TVS MSP
  • The free SFAX Print app
  • A 6-digit post office PIN registered on SFAX

Install it once on the computer that is connected to the printer. A message can be sent to you before you have installed it. It simply waits, and becomes printable as soon as the app has created your key.

The app can also be used on a second computer. Create a key file on the first one and import it on the other, with a passphrase only you know.

Questions

Frequently asked questions

Do I need to install anything to send a message?

No. Senders only need a web browser. Only the post office installs the SFAX Print app.

What if the post office has not installed the app yet?

You can still send. The message waits and shows Waiting for app in your list. As soon as the post office installs the app and it sets up its key, the message becomes printable.

Who can read my message?

Only the post office's SFAX Print app can open it, and it sends the text straight to the printer. The website and the post office staff never see it on a screen. See Security for the honest limits.

What does the post office see?

The sender's name, the date and the status. Not the message, the addresses or the email IDs, until it is printed.

How do I know it was printed?

The status in your list changes from Sealed to Printed.

Which printers work?

Dot matrix printers such as the Epson LX, FX and LQ series and the TVS MSP series. The app refuses to print on other printers.

What if a post office loses its key?

SFAX keeps an encrypted backup of each key. After checking the post office's identity, SFAX can send a recovery file that restores it.

Can the same post office use a second computer?

Yes. In the app, create a key file on the first computer, then choose that file on the second computer after logging in.

Sending and tracking

How long does delivery take?

Your message reaches the post office within seconds. It is printed when the post office presses Print in the SFAX Print app, so the timing is theirs. SFAX does not run the physical hand-over.

What does each status mean?

Waiting for app: the post office has not installed the app yet. Sealed: ready to print. Printed: done. See the Tracking table above.

Will I get a notification?

If email notifications are switched on for this site, you get an email when your message is printed. It never contains the message.

I clicked Send twice. Will it be sent twice?

No. The button is locked while sending, and a repeated request is recognised and kept only once.

I refreshed the page. Did I lose my message?

No. Your draft is saved in this browser tab until you send it or close the tab, and you stay signed in after a refresh.

Can I write in Telugu, Hindi or other languages?

You can write and send in any language, and it is encrypted correctly. But the dot matrix printer prints plain English letters, numbers and common punctuation. Other letters come out as a question mark. The page warns you when you type them.

How long can a message be?

Up to 10,000 characters, which prints on about three sheets. A longer message simply uses as many sheets as it needs: the address sheet comes first and the blank sheet last. Names are limited to 60 characters and addresses to 250.

Changes and cancelling

Can I cancel a message?

Yes, until it is printed. Open it in your list and choose Cancel this message. It is deleted for good.

I typed a wrong address or PIN. What now?

Cancel the message and send it again with the right details. Messages are locked when you send them, so they cannot be edited afterwards.

What if the post office never prints it?

You can cancel and send to another post office. A message that is never printed is deleted after 90 days.

Your data and privacy

How long are messages kept?

Until they are printed, up to 90 days. After printing, 30 days. Then they are deleted automatically. You can cancel earlier.

Does SFAX send my address to anyone?

When you type an address, the site looks up nearby post offices in the public India Post PIN directory. For that, the PIN, or a part of the address you typed, is sent from your browser to that directory. You can skip it and type the PIN yourself. Nothing else leaves your browser unlocked.

I forgot my password.

On the login page choose Forgot password. We email a 6-digit code to your account's email. It expires in 10 minutes. Enter it with a new password of at least 8 characters, and all older logins end. A post office needs a recovery email on file. If yours has none, contact support: after they check who you are, they give you an 8-digit reset code that works on the same screen. Once you are in, add a recovery email under Account recovery so you can reset it yourself next time.

Printers and post offices

Which printers are supported?

Dot matrix printers such as Epson LX-310, LX-350, LQ-310, LQ-350 and FX-890, and TVS MSP 240, 250 and 270, or any printer using a "Generic / Text Only" driver. Inkjet and laser printers are not allowed. If your dot matrix printer is not listed in the app, contact support with its exact name.

The app says no dot matrix printer was found.

Check that the printer is on, connected and installed in Windows. The app shows the printers it found. If yours is there but refused, contact support with its name.

Printing failed, jammed or ran out of paper.

The message stays "To print" and is only marked Printed after the printer accepts the job. Fix the paper or jam, then press Print again. If the faded print is hard to read, replace the ribbon and print again.

Windows says "Windows protected your PC" when I install.

Choose More info, then Run anyway. This appears for apps that are not yet signed with a publisher certificate.

Does the app work offline? How does it update?

It needs the internet to fetch messages, so it cannot print while offline. Messages simply wait. The app updates itself when a new version is released.

Can I use the same post office on two computers?

Yes. In the app, create a key file on the first computer and choose it on the second.

Policies

Privacy, terms and data retention

Privacy policy

What we collect. Your name, email and a password hash. For each message: the sender's name, the name you typed for the receiver, the destination post office PIN, the time and the status. For post offices: the PIN and a recovery email. The message, addresses and email IDs are encrypted before they reach us and we cannot read them.

What we do with it. We use it only to run the service: sending verification codes and printed-message notices by email, and showing you your own list. We do not sell your data or show advertising.

Who helps us run SFAX. Web hosting, the database and the email service are provided by third-party companies. They only handle what is described here. The nearest-post-office lookup uses the public India Post PIN directory, as explained in the FAQ.

Your choices. You can cancel a message until it is printed. To delete your account or ask what we hold about you, contact support.

Keep your password safe and tell us if you think someone else has used your account. Post offices are responsible for printing and handing over messages they receive. We may update these terms, and continued use means you accept the update. To the extent the law allows, SFAX is not liable for losses caused by wrong details, printer faults or delays at a post office.

Message retention and deletion

A message that is never printed is deleted after 90 days. A printed message is deleted 30 days after printing. You can cancel an unprinted message at any time and it is deleted straight away. Deleted messages cannot be restored. The activity log keeps events such as "message sent" or "printed" without any message text.
